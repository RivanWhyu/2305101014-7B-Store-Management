## Deskripsi

Repository ini berisi source code dan dokumentasi hasil pengerjaan Ujian Tengah Semester (UTS) mata kuliah Pemrograman Mobile. Proyek ini merupakan aplikasi Android bernama **Store Management** yang dikembangkan untuk membantu pengelola toko dalam mengelola produk dan aktivitas pembelian pelanggan.

## Deskripsi Pengerjaan UTS

Aplikasi Store Management merupakan aplikasi mobile yang dirancang untuk mempermudah pengelola toko dalam menjalankan aktivitas operasional toko. Aplikasi ini berfokus pada pengelolaan data produk dan proses transaksi pembelian pelanggan.

Melalui aplikasi ini, pengelola toko dapat mengelola informasi barang yang tersedia, melihat daftar produk, serta membantu proses penambahan produk ke dalam transaksi kasir. Aplikasi ini diharapkan dapat membuat pengelolaan toko menjadi lebih praktis, terorganisasi, dan efisien.

## Fitur yang Diimplementasikan

1. **Manajemen Produk**  
   Mengelola informasi produk yang tersedia di toko, termasuk nama dan harga produk.

2. **Daftar Produk**  
   Menampilkan data produk agar pengelola dapat melihat barang yang tersedia.

3. **Kasir dan Transaksi**  
   Membantu proses pemilihan produk untuk transaksi pembelian pelanggan dan perhitungan total belanja.

4. **Pengelolaan Pembelian Pelanggan**  
   Membantu pengelola dalam mengetahui total pembelian pelanggan.

## Persyaratan Menjalankan Aplikasi

Untuk menjalankan aplikasi ini, diperlukan beberapa perangkat lunak dan komponen berikut:

1. Android Studio.
2. Android SDK dengan API 37.
3. JDK yang kompatibel dengan versi Android Gradle Plugin yang digunakan.
4. Gradle Wrapper yang tersedia di repository.
5. Emulator Android atau perangkat Android fisik dengan minimal Android 7.0 (API 24).

## Cara Menjalankan Aplikasi

1. Clone repository dari GitHub:

   ```bash
   git clone https://github.com/RivanWhyu/2305101014-7B-Store-Management.git
   ```

2. Buka Android Studio.

3. Pilih **Open**, kemudian pilih folder repository yang sudah di-clone.

4. Tunggu proses Gradle Sync hingga selesai.

5. Hubungkan perangkat Android atau jalankan emulator.

6. Klik tombol **Run** pada Android Studio untuk menjalankan aplikasi.
